# 🏡 Real Estate Listing Platform  

A full-featured **real estate web application** built with **Django and PostgreSQL**.  
The app allows users to browse, search, and inquire about properties, while realtors and staff can securely manage listings and inquiries through a powerful backend.  

---

## ✨ Features  

- 🔍 **Property Listings** – Browse and filter homes by price, region, and keywords  
- 🏠 **Property Detail Pages** – View property photos, descriptions, and realtor contact info  
- 📝 **User Accounts** – Register, log in, and access a personalized dashboard  
- 📩 **Contact Realtors** – Submit inquiries directly from property detail pages  
- 👨‍💼 **Realtor Management** – Admins can add, update, and manage realtor profiles  
- 📊 **Django Admin Dashboard** – Secure admin panel for staff to manage listings and users  
- 📷 **Media Uploads** – Upload and serve property photos & realtor images  

---

## 🛠️ Tech Stack  

- **Backend:** Django, Django ORM  
- **Database:** PostgreSQL  
- **Frontend:** Django Templates, Bootstrap  
- **Authentication:** Django built-in Auth system  
- **Deployment Ready:** Gunicorn, Nginx, PostgreSQL (production)  

---

## ⚡ Installation & Setup

1. Clone the repository and create a virtual environment  
2. Install dependencies: `pip install -r requirements.txt`  
3. Configure your PostgreSQL database in `settings.py`  
4. Run migrations: `python manage.py migrate`  
5. Create a superuser: `python manage.py createsuperuser`  
6. Start the server: `python manage.py runserver`
